# Варвара

Android-клиент Cloudflare WARP с AmneziaWG: сама подбирает адрес и параметры, чтобы соединение проходило через блокировки.

- Одна кнопка: включить и выключить.
- Регистрация в WARP прямо из приложения, можно ввести свой ключ WARP+ или импортировать .conf.
- Раздельное туннелирование: весь трафик, только выбранные приложения (по умолчанию YouTube, Telegram, Discord и другие) или все, кроме выбранных.
- Сверху видно состояние сети: режим блокировок, внешний IP, трафик.
- Лог можно отправить кнопкой «Поделиться».
- Русский и английский.

## Установка

1. Скачайте `Varvara-<версия>.apk` из [Releases](../../releases/latest).
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. Нужен Android 8 или новее.

Обновление ставится поверх старой версии.

# Varvara (English)

An Android client for Cloudflare WARP with AmneziaWG. It picks the endpoint and the parameters automatically to get through blocking.

Download the APK from [Releases](../../releases/latest), open it on the phone and allow installing from that source. Android 8 or newer.
